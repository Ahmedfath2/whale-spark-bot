# Smart Money Momentum Bot — خطوات الإعداد

بوت مجاني بالكامل يفحص السوق كل 15 دقيقة، ويبعتلك تنبيه تليجرام فقط للحالات النادرة اللي فيها قفزة حجم تداول + تأكيد حركة سعرية (+ تجميع محافظ ذكية لو فعّلته).

---

## 1. إنشاء بوت تليجرام (دقيقتين)

1. افتح تليجرام وابحث عن **@BotFather**
2. ابعتله `/newbot` واتبع التعليمات (اختار اسم واسم مستخدم للبوت)
3. هيديك **توكن** شكله زي: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ` — احتفظ بيه

## 2. الحصول على Chat ID بتاعك

1. ابعت أي رسالة للبوت اللي سويته (حتى لو "hi")
2. افتح في المتصفح: `https://api.telegram.org/bot<التوكن_بتاعك>/getUpdates`
3. هتلاقي رقم تحت `"chat":{"id": 123456789` — ده الـ Chat ID بتاعك

## 3. (اختياري) الحصول على مفتاح Etherscan لتفعيل فلتر المحافظ الذكية

1. سجّل حساب مجاني على **etherscan.io**
2. من إعدادات الحساب → API Keys → أنشئ مفتاح جديد
3. لو ما سويتش هالخطوة، البوت هيشتغل عادي بس بدون فلتر المحافظ (يعتمد على الحجم والسعر بس)

## 4. رفع الكود على GitHub

1. أنشئ حساب GitHub لو ما عندكش
2. أنشئ **مستودع (Repository) جديد** — يفضّل يكون **Public** عشان تاخد دقائق Actions مجانية بلا حدود (لو خليته Private، عندك 2000 دقيقة مجانية شهريًا، غالبًا كافية برضه لكن أضيق)
3. ارفع كل الملفات دي (index.js, watchlist.json, state.json, .github/workflows/scan.yml) للمستودع

## 5. إضافة المفاتيح كـ Secrets

جوا المستودع: **Settings → Secrets and variables → Actions → New repository secret**

أضف الثلاثة دول:
- `TELEGRAM_BOT_TOKEN` = التوكن من خطوة 1
- `TELEGRAM_CHAT_ID` = الرقم من خطوة 2
- `ETHERSCAN_API_KEY` = المفتاح من خطوة 3 (لو سويتها، وإلا سيبها فاضية)

## 6. تفعيل وتجربة

1. روح لتبويب **Actions** في المستودع
2. لو ظهرلك تنبيه "Workflows aren't running"، دوس على الزر لتفعيلها
3. اختار "Smart Money Momentum Scan" من القائمة، ودوس **Run workflow** عشان تجربه يدويًا أول مرة
4. لو كل حاجة مظبوطة، هيبدأ يشتغل تلقائيًا كل 15 دقيقة من هنا وطالع

## 7. بناء قائمة المحافظ الذكية (اختياري، بمرور الوقت)

افتح `watchlist.json` وضيف عناوين محافظ حقيقية (من @lookonchain أو Arkham أو DeBank) بهالشكل:

```json
{
  "wallets": [
    { "label": "اسم توضيحي", "address": "0x..." },
    { "label": "محفظة تانية", "address": "0x..." }
  ]
}
```

## تعديل الحساسية

كل الأرقام دي في أول ملف `index.js` تحت `CONFIG` — عدّلها براحتك:

- `VOLUME_SPIKE_MULTIPLIER` — كل ما زودته، قلّت التنبيهات وزادت دقتها
- `MIN_PRICE_MOVE_PCT` — أقل نسبة تحرك سعر مطلوبة كتأكيد
- `MIN_DAILY_VOLUME_USD` — حد أدنى للسيولة (يمنع عملات يسهل التلاعب فيها)
- `REQUIRE_WHALE_CLUSTER_FOR_ALERT` — خليها `true` لو عايز تنبيهات نادرة جدًا (بس لو فيه تجميع محافظ فعلي)
- `COOLDOWN_HOURS` — أقل فترة بين تنبيهين لنفس العملة

## تنبيه مهم

البوت ده أداة **رصد إشارات**، مش توصية استثمارية ولا ضمان ربح. أغلب التنبيهات ممكن ما تتحولش لفرصة فعلية — قفزة الحجم ممكن تكون بيع ذعر مش شراء. القرار والمخاطرة عليك بالكامل.
